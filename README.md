# 🇬🇧ENG: BlipStar Launcher

An open-source, privacy-focused Minecraft launcher for Windows.

## Privacy & Security

We respect your privacy. BlipStar does not include any telemetry, analytics, or tracking.

- **Microsoft Login:** Required solely to authenticate and launch the game. Your tokens are stored locally on your device.
- **Discord RPC:** Used only to display your current game activity (you can disable it in settings).
- **No Data Collection:** We do not collect, store, or transmit your personal data, cookies, or system information.


## Features (In Development)

- Microsoft OAuth2 authentication
- Offline accounts support
- Discord Rich Presence
- Modrinth modpack installation (`.mrpack`)




🇷🇺Ru:  BlipStar Launcher

Лаунчер Minecraft с открытым исходным кодом, ориентированный на конфиденциальность, для Windows.

## Конфиденциальность и безопасность

Мы уважаем вашу конфиденциальность. BlipStar не использует телеметрию, аналитику или другие средства сбора данных.

- **Вход через Microsoft:** Требуется исключительно для аутентификации и запуска игры. Ваши токены хранятся локально на вашем устройстве.

- **Discord RPC:** Используется только для отображения вашей текущей игровой активности (вы можете выключить это в настройках)

- **Отсутствие сбора данных:** Мы не собираем, не храним и не передаем ваши персональные данные, файлы cookie или системную информацию.



## Функции (в разработке)

- Аутентификация Microsoft OAuth2
- Поддержка автономных учетных записей
- Расширенное отображение статуса Discord
- Установка модпака Modrinth (`.mrpack`)
